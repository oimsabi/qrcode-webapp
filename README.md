# QR Code Generator & Reader

เว็บแอปสร้างและอ่าน QR Code ทำงานฝั่งไคลเอนต์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล
https://oimsabi.github.io/qrcode-webapp/

## ฟีเจอร์

- **สร้าง QR Code** จากข้อความ/ลิงก์ เลือกขนาดและระดับแก้ไขข้อผิดพลาดได้ ดาวน์โหลดเป็น PNG
- **โลโก้ตรงกลาง QR Code** เลือกรูปได้โดยไม่ต้องอัปโหลดไปเซิร์ฟเวอร์ จัดขนาดอัตโนมัติ ใช้ระดับ H และตรวจอ่านก่อนดาวน์โหลด
- **อ่าน QR Code** จากกล้อง (แบบเรียลไทม์) หรือจากไฟล์รูปภาพที่อัปโหลด

## รูปภาพและโลโก้

- รองรับ PNG, JPEG และ WebP ตรวจทั้ง MIME type, ลายเซ็นไฟล์ และการ decode ของเบราว์เซอร์
- ไฟล์ต้องไม่เกิน **10 MiB**, รูปไม่เกิน **24 ล้านพิกเซล** และ **8,192 พิกเซลต่อด้าน**
- ตรวจ dimensions หลัง decode ก่อนสร้าง canvas ภาพสแกนถูกย่อให้ด้านยาวไม่เกิน 2,000 px และโลโก้ไม่เกิน 512 px โดยไม่ขยายภาพเล็ก
- เลือกโลโก้ในแท็บสร้าง QR แล้วกด **สร้าง QR Code** รูปตัวอย่างและปุ่ม **นำโลโก้ออก** จะปรากฏ
- กรอบโลโก้รวมพื้นขาวเริ่มที่ 15% ของด้านพื้นที่ QR ไม่รวมขอบว่าง ถ้าอ่านไม่ผ่านจะทดลอง 13%, 11%, 9% และ 7%
- เมื่อมีโลโก้จะใช้ระดับแก้ไขข้อผิดพลาด H เมื่อนำออกจะคืนระดับที่เลือกไว้ก่อนหน้า
- คงลายสำคัญของ QR ไว้เหนือโลโก้ หากลาย alignment บังโลโก้ทั้งหมด หรือ QR อ่านไม่ผ่าน จะไม่เปิดดาวน์โหลด ให้เปลี่ยนโลโก้ เพิ่มขนาด QR หรือลดความยาวข้อความ
- โลโก้สีขาวล้วนหรือโปร่งใสทั้งหมดไม่มีส่วนที่มองเห็นบนพื้นขาว จึงไม่ผ่านการตรวจโลโก้
- PNG ที่ดาวน์โหลดมีโลโก้และ quiet zone 4 modules ทุกด้านอยู่ในภาพจริง ไม่อาศัย CSS padding
- เปลี่ยนข้อความ ขนาด ระดับแก้ไขข้อผิดพลาด หรือโลโก้แล้ว ต้องสร้าง QR ใหม่ก่อนดาวน์โหลด

การตรวจด้วย jsQR เป็นการตรวจเบื้องต้น ควรทดสอบมือถือและงานพิมพ์จริงก่อนนำไปใช้งาน การใส่โลโก้ไม่ใช่การรับรองมาตรฐาน QR โดยหน่วยงานภายนอก

## การใช้กล้องและข้อมูล

กล้องเปิดเมื่อกดปุ่มเท่านั้น ปุ่มปิดใช้ยกเลิกได้ตั้งแต่ระหว่างรออนุญาต กล้องหยุดเมื่อเปลี่ยนออกจากแท็บอ่าน QR, ซ่อนหน้า/สลับแอป, ออกจากหน้า, เลือกรูปสำหรับสแกน หรืออ่าน QR สำเร็จ ต้องกดเปิดเองเมื่อกลับมาใช้งาน

ข้อความ QR และภาพถูกประมวลผลในเบราว์เซอร์ หน้าเว็บยังโหลด qrcode และ jsQR จาก CDN ตามเวอร์ชันเดิม แต่ไม่มีโค้ดส่งข้อความ QR หรือภาพไปเซิร์ฟเวอร์

## การใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือรันเซิร์ฟเวอร์ static ง่าย ๆ:

```bash
npx serve .
```

หรือ deploy ผ่าน GitHub Pages โดยเปิดใช้งานใน Settings > Pages ของ repo แล้วเลือก branch ที่ต้องการ

## เทคโนโลยี

- Vanilla HTML/CSS/JavaScript ไม่มี build step
- [qrcode](https://github.com/soldair/node-qrcode) สำหรับสร้าง QR Code
- [jsQR](https://github.com/cozmo/jsQR) สำหรับอ่าน QR Code

หมายเหตุ: การสแกนด้วยกล้องต้องเปิดผ่าน HTTPS หรือ `localhost` เนื่องจาก `getUserMedia` มีข้อจำกัดด้านความปลอดภัยของเบราว์เซอร์

## ทดสอบ

Regression tests ใช้ Node.js โดยไม่ต้องติดตั้งแพ็กเกจ:

```bash
node --test tests/security.test.cjs
```

ทดสอบการ render จริง, quiet zone, functional modules, ดาวน์โหลด PNG, responsive layout และ camera lifecycle ใน Chromium ด้วย Playwright (ใช้ Node.js รุ่น 22 ขึ้นไป):

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser.cjs
```

หากใช้ Chrome ที่ติดตั้งอยู่แล้ว ให้ตั้ง `BROWSER_EXECUTABLE_PATH` เป็น path ของ executable แทนการติดตั้ง Chromium และตั้ง `ARTIFACT_DIR` เพื่อเลือกโฟลเดอร์เก็บ screenshot/PNG/ผลทดสอบ (ค่าเริ่มต้น `.test-artifacts/`)

Browser tests ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด CDN bundles รุ่นที่แอปใช้ ใช้ MediaStream จาก canvas สำหรับทดสอบ ไม่มีการเปิดกล้องจริง การคืน functional modules อ้างอิง pixel mapping ของ qrcode 1.4.4 จึงต้องรันทดสอบ pixel checks ใหม่เมื่อเปลี่ยนไลบรารีรุ่นนี้
